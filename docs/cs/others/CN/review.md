关于期末考试，闭卷，80道选择题+10道判断题+1道大题，先说复习：计网本身知识点很广泛，因此掌握内容需要从宏观角度出发，然后一些重点内容掌握细节。我个人复习方法：自己写的笔记 + PPT（推荐一下xht老师最后的总结PPT）+ 王道 + lkj100题 + 杂七杂八的别的班的小测作业题目。计网的复习不要想着一下就到位，由于知识点的宽泛，建议考试周前先过一遍基础内容，掌握大致印象，然后在准备刷题之前再过一遍。和OS一样，王道不要过于提早地刷，我也是用了大概两天左右的时间做完了王道，王道内容和课堂内容可能会存在出入（计网内容本身出入就挺多的），也要保持审慎的态度。我建议，有时间的同学一定要刷王道，个人经验下来，选择题很多类似于王道题型，但一些不太重要的知识点不用过于钻牛角尖（例如一些课堂一笔带过的）。lkj100题一定要做，可以让你知道哪些内容掌握的还比较薄弱，今年考试应该考了一些原题。最后是总结和梳理，如果这些做完你还有空闲时间，不妨按照自下而上的顺序进行关键知识点的梳理（按照物理层-链路层-网络层-传输层-应用层的顺序），将一些比较容易混淆的知识点进行梳理，例如什么协议在哪一层，其下的协议是什么，其端口是什么等等。

我建议王道不需要很早就开始刷，我考试前提前半个月左右就刷完了整本王道，后面快考试的时候遗漏的地方还是蛮多的，所以最好是看考试时间，基本上三天就可以刷完王道了。lkj100题，我建议是在复习之前做，因为只有这样你才知道是如何出题的，才能更好的面向期末考试复习。今年qjs出题，考王道的原题并不是很多，倒是他小测和作业的题目出现的次数比较多。因此在之后考试，我建议是打听清楚是哪位老师出的题目，针对他的小测和作业做高质量的拟合，还有他的复习课，反复观看，酱紫效果比较好一点。最后考试题型是80个选择题，8个判断题，12个大题（其实也是填空），一定要注意时间分配。复习的时候不需要太care那些晦涩难懂的计算题，主要是把一些零零碎碎的知识小点过一遍，记一遍，就能很好的速通这么考试。
